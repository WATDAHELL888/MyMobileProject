# MOBILE PROGRAMMING PROJECT
## Smart Finance AI

## Feature :
1.ระบบธุรกรรมที่ประกอบไปด้วยกราฟการเงินของ app ที่จะแสดงธุรกรรมของเรา รวมถึงค่าเงินในบัญชี(income ที่เรา input เข้าไปเอง) ที่แสดงทั้ง expense และ income  
2.ระบบ add transaction หรือเพิ่มธุรกรรมใหม่ที่จะมีให้ใส่ชื่อรายการ note ว่าเราใช้กับค่าอะไรหรือเราซื้ออะไรบ้าง หรืออาจจะเป็น income ว่าเราได้เงินมาเท่าไหร่รวมถึง category ว่าเราใช้กับค่าอะไรเช่น ค่าอาหาร ค่าเดินทาง ดูหนัง หรือ เราได้เงินจากไหน เงินเดือน freelance ฯลฯ พร้อมหน้าต่างที่แสดงรายการธุรกรรมของเราทั้งหมด  
3.ระบบ group การหารเงินต่างๆ ที่จะมีให้สร้าง group และ add member ที่หารเงินร่วมกันเข้ามาใช้งานให้สะดวกขึ้น โดยใน group จะมีระบบที่แสดงรายการธุรกรรมของเรา หน้าต่าง balance ที่แสดงว่าใครใช้จ่ายไปเท่าไหร่ หน้าต่าง settlement ที่สรุปยอดว่าใครต้องจ่ายให้ใคร EX. A -> B , B -> C ระบบจะสรุปให้ว่า A -> C ไปเลยเพื่อความสะดวกไม่ต้องโอนหลายต่อ และหน้าต่าง summary ที่สรุปการเงินของกลุ่มและจำนวน member รวมถึงระบบ AI วิเคราะห์ที่เอาไว้วิเคราะห์ว่ากลุ่มนี้ใช้เงินกับค่าอะไร ยังไง เท่าไหร่ ควรจะประหยัดยังไง  
4.ระบบ AI chat ที่เอาไว้ถามตอบกับ AI เกี่ยวกับการเงินของเรา Ex.เราจะประหยัดเงินอย่างไร การเงินของเรามีผิดปกติไหม เราใช้เงินกับอะไรมากที่สุด
5.widget ที่จะแสดง balance ของเรารวมถึง spend ว่าเราใช้จ่ายไปเท่าไหร่ และมีหน้า AI insight ที่วิเคราะห์การเงินของเราแบบสั้นๆว่าเราใช้เงินกับค่าอะไรเยอะ หรือถ้าเยอะเกิน AI ก็ควรจะเตือน
